Usage: main-bulk-rotate-iam-keys.sh <info-file> <action>

  <info-file>  File with one "iam_username|aws_cli_profile" per line
  <action>     list | inactivate | delete | create



Typical rotation, one action at a time (see "Rotation order" in README.md).
Each change asks "(y/n)" first; type y to do it, anything else skips the user.

./main-bulk-rotate-iam-keys.sh info/test_ALL.txt list         # only shows keys, changes nothing

./main-bulk-rotate-iam-keys.sh info/test_ALL.txt create       # user has 1 key -> adds a 2nd, prints "ID,Secret"
	(copy the secret now: it is shown once and never saved to a file)
	(update the application with the new key, then continue)

./main-bulk-rotate-iam-keys.sh info/test_ALL.txt inactivate   # user has 2 Active keys -> inactivates the oldest
	(verify with "list" that the application still works: check Last Used)

./main-bulk-rotate-iam-keys.sh info/test_ALL.txt delete       # deletes the oldest Inactive key only

The script can be started from any directory; the info-file path is relative
to where you start it (or absolute).


See examples/ : one file per action with the command and the expected result
(list.txt, inactivate.txt, delete.txt, create.txt).
